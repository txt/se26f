# Talks: the two rubrics

Each team gives two in-person talks: one **tool talk**, one **task
talk** (see the [schedule](../../README.md) for your slot). Each is
15 minutes and worth 7 marks. Talks are graded live, as they happen
— every row below is decidable the moment it occurs.

## The tool talk (7 marks)

Teach us a tool. Not a sales pitch — a working session.

| Marks | For | Live check |
|------:|-----|------------|
| 2 | **The demo runs** — the tool does something real, live or recorded | 2 = ran clean; 1 = stumbled but recovered; 0 = slides about a demo |
| 2 | **Taught, not sold** — we could use the tool tomorrow | a workflow shown start-to-finish, not a feature tour |
| 1 | **One idea we remember** — stated in one sentence | if the grader cannot write it down as you say it, it did not land |
| 1 | **Timing** — done in 15 | minute sixteen = 0 |
| 1 | **Delivery** — talking to us, not reading; team on stage | |

## The task talk (7 marks)

Teach us a task from your project. What you tried, what broke, what
you would do differently.

| Marks | For | Live check |
|------:|-----|------------|
| 2 | **The task, shown** — what you tried, as artifact (code, output, diff) | described-only caps at 1 |
| 2 | **What broke, and why** — honest failure analysis | a real failure well explained scores full; "everything worked" is suspicious and will be probed |
| 1 | **Do differently** — one specific, actionable change | "communicate better" = 0 |
| 1 | **Timing** — done in 15 | minute sixteen = 0 |
| 1 | **Delivery** — talking to us, not reading; team on stage | |

Ways to lose marks, both talks: slides full of bullet points; reading
to us; minute sixteen. An honest failure never costs you — a hidden
one does.
